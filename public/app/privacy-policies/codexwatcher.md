## 使用与隐私说明

### 开源与运行

**Codex Watcher** 是独立第三方开源项目，与 OpenAI 无隶属关系。项目采用 MIT 许可证，通过 [GitHub 仓库](https://github.com/ximatai/CodexWatcher)提供源码，不通过 App Store 分发。

当前为源码预览版，尚无签名、公证的安装包。运行需要 **macOS 14+**、**Xcode** 和单独安装的 **Codex CLI**；请按仓库 README 从源码构建，并在官方浏览器页面连接 ChatGPT 账号。

### 用量与时间进度

应用展示账号接口返回的额度窗口、已用比例、重置时间及重置卡信息。字段是否可用取决于账号套餐和服务端返回值。

**偏移 = 实际用量 − 自然时间进度。** 自然时间进度根据窗口长度与下次重置时间推算，包含睡眠和休息时间。正值表示消耗超前，负值表示滞后。数据读取失败、超过 10 分钟未更新或周期已结束时，停止展示偏移。

### 数据与隐私

- 应用通过本机 Codex CLI 与官方服务交互，不使用开发者自建后端。
- 不读取聊天内容，不发起模型推理，不记录令牌、登录链接或原始协议数据。
- 使用独立的本地运行目录，账号凭证由 Codex CLI 的系统钥匙串存储管理。
- 外观、菜单栏显示和隐藏邮箱等偏好保存在本机。
- 待确认重置记录保存在本机，用于保存账号关联、卡片 ID 和重试标识，不含密码或访问令牌。

应用会读取并展示账号、套餐和额度信息。“隐藏邮箱”可遮盖界面中的邮箱；CLI 自身及官方服务的数据处理行为由相应服务负责。

### 重置卡

点击“使用”会先打开确认页；明确确认后才会发送消费卡片的重置请求。**重置会消耗卡片且无法撤销，真实重置操作目前尚未验收。**

超时不代表操作失败。重试会复用原请求标识并重新发送写请求，可能完成首次消费。结果未知时，请保留本地待确认记录，并遵循应用与仓库中的重试说明。

### 项目反馈

使用问题和功能建议请通过 [GitHub Issues](https://github.com/ximatai/CodexWatcher/issues)反馈。安全问题请遵循仓库的 [安全与隐私说明](https://github.com/ximatai/CodexWatcher/blob/main/SECURITY.md)，不要在公开反馈中包含令牌、登录链接或账号凭证。
